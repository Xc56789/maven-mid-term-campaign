# Provenance

Final campaign theme: Maven 概念侦探社. Three visual editions: archive, night investigation and campus club. The latest standalone HTML and its 11 embedded downloads were prepared on 2026-10-02.

The repository includes the exact delivered standalone HTML, PNGs, PDFs and TXT files. Portable source was extracted from the authoring scripts and prepared independently of the original workspace directory. Script paths are relative to this repository.

Reference inputs supplied by the owner:

- `assets/references/activity-example.pdf`: MAVEN 期中充电站; original gift configuration and drawing rules.
- `maven-character-reference.jpg`: identity reference for new illustrations; the original grade-related slogan was not adopted as an activity promise.
- `maven-blue-poster-reference.png`, `national-day-reference.jpg`: supplied brand illustrations.
- `tote-design-reference.png`, `tote-photo-reference.png`, `maven-keychain-reference.png`: product references. The keychain is not promised as a campaign reward.

Images were generated with the built-in image generator from the provided identity reference. Parameters: one source identity image, nontransparent output; three independent new compositions. Original returned PNGs are in `assets/illustrations/`. Prompt texts are in `illustration-prompts.md`. A rerun can produce a different image; the saved PNG is the reproducible visual input.

The current public-facing inventory retains the original PDF's planned quantities and both daily and final drawings. The earlier alternative of guaranteed gifts after pairs of tasks is not part of this delivered version.

No production application source, course export, student records, chat logs, credentials or server environment files were used as repository inputs. Repository checks are material reproduction checks, not an evaluation of Maven answer quality or real-phone delivery.
